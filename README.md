# Code for Sharafeldin et. al (NeurIPS, 2026): Learning Actionable Information Maps for Multimodal Active Sensing in Hawkmoths

Use Python 3.10. From this folder, install the dependencies and start Jupyter:

```sh
python -m pip install -r requirements.txt
python -m jupyter lab
```

Run each notebook from its first cell in a separate kernel. Training uses CUDA when available, otherwise CPU. Checkpoints are generated by the notebooks and are not bundled, except for the perception checkpoint used for RL training in the manuscript which is included with the code.

## Nectary search

1. Run `NectarySearch/nectary.ipynb` to train perception, save `NectarySearch/checkpoints/perception.pt`, and view reconstructions, modality weights, and uncertainty-reduction maps.
2. Run `NectarySearch/exploration_pretraining.ipynb` to load perception and pretrain exploration. Set `PRETRAIN_ENVIRONMENT` to the condition needed by your experiment (`flat-cross`, `funnel-cross`, `flat`, or `funnel`). It saves `checkpoints/exploration_<condition>.pt` inside `NectarySearch`.
3. Train and evaluate an experiment from an existing configuration:

```sh
cd NectarySearch
python run_experiment.py train-eval --config configs/experiments/mode_switch_flat-cross.json
```

Use `train` instead of `train-eval` for training alone. Configurations specify the checkpoint, environment, controller, training budget, and evaluation suites. Outputs go to `results/experiments/`. Use `python run_experiment.py --help` for other commands. 

## Biological trajectory analyses

Run `FlowerTracking/moth.ipynb` for the flower-tracking model, UR maps, and strategy and light-condition comparisons. Inputs are in `FlowerTracking/data/`. The species comparison uses *D. elpenor* and *M. stellatarum*: `Tracks_M*` denotes Macroglossum, while `Tracks_Ma*` denotes Manduca. See the included data README and the [Stöckl et al. dataset](https://doi.org/10.5061/dryad.94kt2).

Run `NectarySearch/deora_analysis.ipynb` to reproduce the biological-versus-matched-random plots from `NectarySearch/results/deora_replay_summary_2030.csv`. The raw inputs for its example trajectory are included under `data/deora_et_al/`. The notebook analyzes saved replay results; rerunning the full replay collection requires the complete source trajectory dataset and a perception checkpoint.
